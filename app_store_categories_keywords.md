## 📱 WAS DU DAMIT MACHEN KANNST:

### 1. **App Store Connect (iOS)**
```
Wo eintragen:
- App Information → Keywords (100 Zeichen max)
- Trenne Keywords mit Kommas
- Keine Leerzeichen nach Kommas
- Beispiel: Familie,Kalender,Chat,Organisation,Termine,Fotos,Eltern,Kinder,Sync

Kategorie wählen:
- App Information → Category → Lifestyle
- App Information → Secondary Category → Social Networking
```

### 2. **Google Play Console (Android)**
```
Wo eintragen:
- Store-Einträge → App-Details → Kategorie: Lifestyle
- Store-Einträge → Store-Eintrag → Tags (bis zu 5)
- Verwende: Familie, Kalender, Organisation, Chat, Fotos

Beschreibung optimieren:
- Keywords natürlich in App-Beschreibung einbauen
- Besonders in ersten 80 Zeichen wichtig (Vorschautext)
```

### 3. **ASO (App Store Optimization) Strategie**
```
Keyword-Dichte:
- Verwende Haupt-Keywords 2-3x in der Beschreibung
- Variiere Keywords (Familie/Familienkalender/Familienleben)
- Nutze Keywords in App-Name und Untertitel

Lokalisierung:
- Deutsche Keywords für DACH-Region
- Englische Keywords für internationale Märkte
- Eventuell später: französische, spanische Keywords
```

## 🎯 KEYWORD-RECHERCHE TIPPS

### Tools zur Keyword-Analyse:
1. **App Store Connect Analytics** (nach Release)
   - Zeigt, über welche Suchbegriffe Nutzer deine App finden

2. **Sensor Tower / App Annie** (kostenpflichtig)
   - Keyword-Rankings von Konkurrenz-Apps analysieren

3. **Google Keyword Planner** (kostenlos)
   - Suchvolumen für Keywords checken
